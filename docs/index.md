# luish

luish is a POSIX `sh` for Linux, written in Rust. The long-term aim is a shell that can replace zsh as a daily
driver, built on a core that is as fast as [dash](http://gondor.apana.org.au/~herbert/dash/).

luish is at an early stage. Most of POSIX is implemented, but expect rough edges.
