Goals for luish

- Eventually replace zsh as my default shell
- As fast as dash when only simple functionality is used
- Caching of parsing (e.g., login scripts). Starting a new shell on a previously parsed script should be very fast, ideally instantaneous.
- Support for plugins
- Better support for modern terminal features (e.g., true color, Unicode)
- Better support for modern shell features (e.g., arrays, associative arrays, process substitution)
- Better support for scripting (e.g., better error handling, better debugging)
- Better support for interactive use (e.g., better tab completion, better history management)
- Builtin support for SSH use, including running in a client/server mode with predictive terminal input and potentially client-side history management &c
